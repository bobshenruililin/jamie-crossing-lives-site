# When lives span a border

Working presentation and research companion for Jamie Ko's AsiaGlobal Fellows research.
Research and presentation: Jamie Ko. Visual support: Bob.

This public export contains audience-facing materials and public source links.
The full private research and authoring repository is separate.

The study is exploratory and Hong Kong-centred, informing questions for Singapore–Johor.
Statistics, programme descriptions, forecasts and proposals are distinguished throughout.
Comparative examples and future reading avenues do not establish transferable effects.

Open `index.html` through an HTTP server for the unified visual research feature, or
`presentation.html` for the manually advanced presentation. `presentation.pdf`
contains the complete static draft. The previous companion remains at `research.html`,
and visual studies remain at `samples/`. Font licences are included in `fonts/`.

The optional route game uses invented demand and rules. The spatial model is a conceptual
illustration, not measured geographic data. Selected field photographs were supplied
by Bob and Jamie. This is a review edition for Jamie's feedback.

The presentation follows Script flow v3 checked on 2 November 2026, with at least
fourteen individual/group conversations and three Shenzhen trips. It includes
the revised questions for further inquiry. The website remains the prior review edition.
The original r2154 presentation PDF remains at presentation-r2154.pdf. Maps, policy
documents and research collections extend the main narrative with their own sources
and limits. This is a working draft for review, not a final approval by Jamie.
